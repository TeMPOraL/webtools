JSON/XML Explorer — quick reference

Path query

$.a.b child   a[0] index   a[*] wildcard   a[1:3] slice   $..price recursive descendant search   a["odd key"] quoted key   items[?(@.qty>1)] filter (== != > < >= <=).
XML attributes are addressed as @name, text as #text. If a step matches several sibling nodes (e.g. repeated XML elements), [n] selects among them; otherwise it indexes into that node's own children.

Fields panel

Toggle a key name off to hide it everywhere in the tree/graph. Row ⋮ menu adds ad-hoc Hide/Isolate (show only this key, plus the ancestors needed to reach it) without opening the panel.

Keyboard

/ focus query   Esc close/blur   Ctrl+Enter in the source box parses immediately   Arrow keys navigate a focused tree row, Enter/Space toggles it.

Graph view

Drag / one-finger pan, wheel / pinch to zoom, tap a node to expand or collapse it. Everything stays local — nothing is ever uploaded.
